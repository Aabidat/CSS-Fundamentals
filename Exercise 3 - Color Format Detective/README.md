# Color Format Detective
## Exercise-3
| # | Description | Format Name | Color Name |
| :--- | :---: | :---: | :--: |
| A | Uses three numbers separated by commas inside parentheses | rgb | rgb(25,25,25) |
| B | Starts with a hash symbol and contains six hexadecimal digits | hex | #3186FF |
| C | Describes color using hue, saturation, and lightness | hsl | hsl(100,50%,25%) |
| D | Uses a plain English word recognized by CSS | name color | aqua |

## 1.
- Hex format: `color : #FF0000`
- RGB format: `color : rgb(255,0,0)`
- hsl format: `color :hsl(0, 100%, 50%)`

## 2.
rgb(255, 0, 0) gives pure red whiles rgba(255, 0, 0, 0.5) gives a semi-transparent red. The 'a' in the rgba stands for the alpha value that controls transparency, meaning you can see part osf the background through the color.
## 3.
`#000000`: `rgb(0,0,0)` is color black
`#ffffff` : `rgb(255,255,255) is color white
