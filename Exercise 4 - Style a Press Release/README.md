# Exercise-4

## Styling a press release
- In this exercise, I wrote the CSS for a press release page. The HTML file was already provided, so I only created the press.css file and linked it. I imported two Google Fonts Playfair Display for headings and Source Sans Pro for body text. I used different color formats across the stylesheet, hex for the background, RGB for body text, HSL for headings, and a named color for the dateline. I also used p:first-of-type to add word spacing to only the first paragraph without touching the HTML. 
- I tested text-decoration: line-through on the dateline, it made the date look crossed out meaning the date line is no longer valid , it has been cancelled and the font-size made the size of the text look smaller, which is wrong for a press release.
